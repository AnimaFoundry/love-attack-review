# BF-01C pre-execution review — 26 October 2026

This review precedes the single authorized cohort. No BF-01C model request has
been initiated at this checkpoint. The human explicitly authorized completing
validation, freezing the finite budget and executing this 32-slot local study.

## Fixed scope and finite budget

The exact eight newly authored synthetic records and 32 full request bodies are
in `tasks.json` and `requests.json`. Four conditions use two output contracts and
raw versus schema-constrained generation. No emotional or legitimacy framing,
private material, external customer data or third-party benchmark is included.
Independent internal review checked all eight manually specified state/value/row
answers against the source records. Deterministic lookup is the strong baseline;
the gate and baseline share a parser, so algorithmic independence is not claimed.

`PLAN.md` fixes the predesignated schema-evidence gate at at least 7/8 joint usable
answers, including all four unknown/absent cases, complete execution and intact
budget/metadata. It also fixes the no-selection and no-retuning rules. Each of
the 32 initiated slots, including the first schema compatibility observation,
has a 256-token/30-second ceiling. Total limits are 8,192 generated tokens and
600 seconds of inference wall time, concurrency one, no retries or auxiliary
inference, no new model download and USD 0 external API fees.

## Completed offline checks

The complete pilot suite passed **95 unittest methods** in the local Windows
environment before freezing. These include source/target and contract controls,
strict wire versus decoded-schema semantics, scoring and gate rules, transport
completion, bounded calls, raw evidence replay, immutable files, usage budgets,
model identity, missing evidence and tampering controls. Tests use synthetic
bytes and fake transports; none executes a model. Unit-method counts are not
independent scientific observations. Internal AI-assisted review is not external
peer review.

During test development, the default system temporary directory denied fixture
writes/cleanup. Test scratch was moved to a checked workspace `build/` directory;
the final runtime suite passed 32/32, scorer suite 20/20 and independent saved-byte
suite 14/14. These setup failures are retained in the internal work record and
are not model failures. All new text files were normalized to LF before freezing;
the exact model template/license hashes remained unchanged.

Pre-execution static review found that durable request/journal writes could
consume the global allowance after its initial calculation. The runner was
corrected before inference: it recalculates the dispatch allowance, enforces the
absolute global transport deadline, and preserves a reserved-but-unsent slot if
logging exhausts the budget. Three new fake-clock regression methods passed.
Saved replay distinguishes the initial reservation from the actual send grant.

`verify_saved.py` independently traverses the retained request/response files,
journal, frozen schedule and metadata, reparses envelopes and recomputes counts,
budget consistency and scores. It accepts a documented stopped prefix but never
silently drops an initiation. It verifies retained-artifact consistency, not
external authenticity or truthful historical clocks.
